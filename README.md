# XDoku 🎮  
**Кроссплатформенное приложение для игры в судоку с онлайн-функционалом**
> Ссылка на Miro: https://miro.com/app/board/uXjVI8V73Is=

## О проекте  
**XDoku** — это современная реализация классической головоломки судоку, которая сочетает в себе интуитивный интерфейс и продвинутые возможности для трекинга прогресса. Проект создан в рамках курсовой работы и фокусируется на:  
- **Интерактивности**: Игра с удобным управлением и визуальной обратной связью.  
- **Социальной составляющей**: Регистрация пользователей, глобальная таблица лидеров и сохранение статистики.  
- **Персонализации**: Возможность выбора уровня сложности и автоматическое сохранение текущей игры.  

## Возможности ✨  
- **Регистрация и профиль**  
  Создавайте аккаунты, чтобы отслеживать свои достижения.  
- **Таблица лидеров**  
  Соревнуйтесь с другими игроками в рейтинге лучших игроков.
- **Статистика**  
  Анализируйте прогресс: количество решённых головоломок, среднее время, уровень сложности.  
- **Сохранение прогресса**  
  Приложение автоматически сохраняет текущую игру при выходе.  
- **Настройка сложности**  
  Выбирайте между уровнями: Простой, Средний, Сложный, Эксперт.  

## Технологии 🛠️  
- **Язык**: C++ с акцентом на объектно-ориентированное программирование.  
- **Графика**: OpenGL (GLFW + GLAD + Dear ImGui) для кроссплатформенного рендеринга.  
- **Хранение данных**: PostgreSQL + библиотека `pqxx` для работы с базой данных.
- **Удобство разработки**: Использование Аlembic для быстрого внесения изменений в схемы таблиц в базе данных
- **Архитектура**: Паттерн MVP (Model-View-Presenter) для чистоты кода и расширяемости.  

## Статус разработки 🚧  
Проект находится в активной разработке.  
**Текущая цель**: Реализация онлайн-многопользовательских функций и улучшение алгоритма генерации судоку.
